Access & Privacy

Barangay official permissions

  • View all dog registration requests.
  • Approve or reject registrations.
  • View all citizen incident reports.
  • Update incident report status.
  • View community monitoring summaries.
Privacy rule: Owner names and addresses are administrative information. Keep them restricted to authorized barangay personnel. Citizens can only view public dog details.

Prototype limitation: the system stores data in this browser using localStorage. Real multi-device use requires a secure online database, server-side authentication, role-based access control, and audit logs.
